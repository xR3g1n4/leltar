# leltar
Ez itt a vizsgaremekünk repository-ja.

A projekt egy leltározó rendszer lesz.
Célja egy k-poppal foglalkozó bolt raktárának rendszerezése, szortírozása valamint a készlet számontartása lesz.


Futtatási útmutató: 

1. lépés.: miután letöltöd a zip fájlt, bontsd ki. és nyisd meg az egész mappát a Visual Studion keresztül.
2. lépés.: nyisd meg a git bash terminált, és írd be node server.js parancsot a szerver elindításához.
3. lépés.: válassz ki egy böngészőt, majd be kell írni hogy, localhost:3000.

Bejelentkezés
1. lépés.: a login felületen a felhasználó és jelszó mezőben meg kell adni a helyes adatokat. (adminisztrátor: Nagy Anna jelszó : pass111 // dolgozó: Katika jelszó: pass123)
